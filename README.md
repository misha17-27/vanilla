# Vanilla.az — редизайн

Новый сайт для [vanilla.az](https://vanilla.az/) — кондитерской в Баку (бенто-торты и cake to go, продажи только по предзаказу, без онлайн-оплаты).

## Актуальная версия — `site/` (PHP, многостраничный)

Премиальный пастельный дизайн в фирменных цветах vanilla.az (#FD4680 розовый, #16527F тёмно-синий, нежно-голубой), фирменный логотип, шрифты Cormorant Garamond + Montserrat.

**Запуск локально:**

```bash
php -S localhost:8123 -t site site/router.php
```

и открыть `http://localhost:8123/`. На хостинге с Apache содержимое `site/` кладётся в корень домена — `.htaccess` уже настроен.

**URL-структура повторяет vanilla.az (WordPress) — SEO-позиции сохраняются:**

## Админ-панель `/admin/`

При первом входе задаётся пароль (хранится хешем в `site/data/admin.pass`, в git не попадает). Позволяет добавлять, редактировать и удалять товары каталога: название, тип, цена, фото (пересжимается в квадрат 800×800), SEO-заголовок и описание. Адрес страницы существующего товара не меняется — это защищает позиции в поиске. Перед каждым сохранением создаётся резервная копия `data/catalog.json` в `data/backups` (хранятся последние 20).

Защита: хеш пароля, ограничение 5 попыток входа за 15 минут с одного IP, CSRF-токены, проверка загружаемых фото по содержимому файла.

## Конструктор торта `/konstruktor/`

Клиент выбирает цвет крема, ставит картинку (готовые стикеры или своё изображение — можно перетаскивать и менять размер) и пишет надпись — превью обновляется мгновенно. При оформлении заказа макет отрисовывается в canvas, загружается на сервер и уходит ссылкой в WhatsApp вместе с размером, начинкой и контактами.

**SEO:** title и description каждой страницы (включая все 111 товаров) сняты с текущего vanilla.az и лежат в `site/data/catalog.json` и `site/data/seo.json`. Canonical указывает на `https://vanilla.az`. Старые WP-адреса (`/tortlar/`, `/biskvit/*`, `/my-account/` и т.д.) отдают 301-редиректы. Товарные страницы: фото, цена (реальная из WooCommerce), кнопка WhatsApp и табы «Описание / Начинки / Срок изготовления / Доставка».

**Мультиязычность:** русский — основной, AZ и EN — переключатель в шапке (`?lang=`, хранится в сессии). Тексты — в `site/lang/{ru,az,en}.php`.

**Данные:** товары и контакты — в `site/includes/config.php`; общие шапка/подвал — `site/includes/`.

**Ключевые решения:**
- Заказ только через WhatsApp (+994 55 215 63 43) — кнопки с готовым текстом на языке посетителя
- Никаких упоминаний оплаты (по требованию владельца)
- Секция «Одно сообщение — один торт» — диалог WhatsApp как инструкция заказа
- Секция «повода» в стиле Instagram-хайлайтов (розовые круги с иконками)
- Размеры/цены: бенто 300–350 г / 25 ₼, 750–800 г / 35 ₼, 1200–1500 г / 60 ₼; cake to go 2 шт 170–190 г / 25 ₼, 2 шт 270–290 г / 30 ₼ (в стакане + деревянная ложечка + свечка)
- Начинки: ванильный / шоколадный бисквит / красный бархат + крем-чиз, правило «1 бисквит + 1 начинка»
- Доставка: Пн–Пт курьер 11:00–20:00, Bolt Delivery 11:00–22:00; Сб 11:00–14:00; Вс — выходной

## Архив — первые концепты главной

`v1/` (нежный крем), `v2/` (тёмный шоколад), `v3/` (игривый cute) — статические HTML с переключателем RU/AZ/EN. Корневой `index.html` — страница выбора.

## Лента Instagram на главной

Сетка последних 12 постов @vanilla_cake_az. Данные — в `site/data/instagram.json` (картинка + ссылка на пост), миниатюры 480×480 — в `site/assets/img/insta/`. Ссылки CDN Instagram протухают, поэтому картинки хранятся локально.

**Как обновить ленту:** заменить файлы `ig-01.jpg…ig-12.jpg` свежими квадратными фото и поправить ссылки постов в `instagram.json`. Для автообновления нужен токен Instagram Graph API (создаётся владельцем аккаунта) — тогда добавим PHP-скрипт, который будет сам подтягивать свежие посты.

> Все фото товаров локальные (`site/assets/img/products`, 108 файлов, ~8,6 МБ) — сайт не зависит от старого vanilla.az и готов к переезду на хостинг.
