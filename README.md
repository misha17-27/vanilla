# Vanilla.az — редизайн

Новый сайт для [vanilla.az](https://vanilla.az/) — магазина бенто-тортов и cake to go в Баку (продажи только по предзаказу, без онлайн-оплаты). Цель — современный дизайн и высокая скорость: чистый HTML/CSS/JS без фреймворков, дальше переносим на PHP.

## Варианты главной страницы

| Версия | Стиль | Файл |
|---|---|---|
| **V1 — Крем** | Нежный премиум: кремово-розовая палитра, серифная типографика, арки | [`v1/index.html`](v1/index.html) |
| **V2 — Шоколад** | Тёмный editorial: шоколад + карамель, крупные заголовки, бегущая строка | [`v2/index.html`](v2/index.html) |
| **V3 — Cute** | Игривый бенто-стиль: стикеры, полароиды, WhatsApp-чат как инструкция | [`v3/index.html`](v3/index.html) |

`index.html` в корне — страница выбора со встроенными превью всех трёх версий.

## Что внутри каждой версии

- Полностью на азербайджанском, контент и фото взяты с текущего vanilla.az
- Заказ через WhatsApp (+994 55 215 63 43) — кнопки с готовым текстом сообщения по каждому товару
- Секции: hero, преимущества, меню (bento / cake to go), размеры, «как заказать», вкусы, о нас, FAQ, Instagram, контакты
- Адаптив: мобильное меню, липкая CTA-панель снизу на телефоне
- Скорость: один HTML-файл на версию, инлайн-CSS, lazy-загрузка фото, `preconnect`, без библиотек
